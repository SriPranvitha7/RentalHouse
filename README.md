# RentalHouse

A web-based rental house search application where tenants can 
find rental properties on an interactive Google Map.

## Tech Stack
- HTML, CSS, JavaScript
- Google Maps API
- Java, JDBC, MySQL (backend - in progress)

## Features
- Search properties by location, house type and rent range
- Interactive Google Maps integration
- Property listing form for owners
- Direct owner contact details

## How to Run
1. Clone or download this repository
2. Get a free Google Maps API key from https://console.cloud.google.com/
3. Replace YOUR_API_KEY in map.html with your actual key
4. Open index.html using VS Code Live Server
