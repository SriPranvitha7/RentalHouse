About the Project

HouseFinder

A web-based rental search platform built to connect tenants and property owners directly — without brokers or fees.

What this project does

HouseFinder simplifies the house-hunting process by combining property listings, interactive map visualization, and location-aware search into one platform. Tenants can explore properties geographically, while owners can list houses in minutes.

The project was built as a full-stack web application using HTML, CSS, and JavaScript on the frontend with Google Maps API for map rendering, and Java with JDBC and MySQL for the backend data layer.

Key features

🗺️
Interactive map

Properties are plotted using real GPS coordinates on Google Maps. Tenants see exactly where each house is located.

🔍
Location-aware search

Search by city name, house type, and rent range. The map pans automatically to the searched area.

📞
Direct owner contact

Owner phone numbers are shown in property info windows — no agents, no commissions.

📋
Easy property listing

Owners can list houses by filling a simple form with location coordinates, rent, and contact details.
